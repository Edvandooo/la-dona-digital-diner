# La Dona Vintage Forge

Crie um site completo, premium e extremamente bem acabado para a LA DONA HAMBURGUERIA.

O objetivo é criar um site REAL DE HAMBURGUERIA, com foco em apresentar a marca, cardápio, produtos, experiência e principalmente converter visitantes em pedidos.

IDENTIDADE VISUAL

Use o logo oficial fornecido como asset principal da marca.

O logo deve ser utilizado EXATAMENTE como foi enviado.

NÃO recrie.
NÃO redesenhe.
NÃO reinterprete.
NÃO gere outro logo.
NÃO altere a tipografia.
NÃO altere as proporções.
NÃO altere os elementos.
NÃO aplique modificações que mudem sua identidade.

A identidade visual deve partir do logo:

* preto e branco;
* vintage americano;
* hamburgueria artesanal;
* diner clássico;
* selo circular;
* forte personalidade;
* estética premium;
* detalhes retrô.

A execução precisa ser moderna, sofisticada e tecnológica, sem fazer o site parecer antigo.

DIREÇÃO VISUAL

Criar uma estética:

VINTAGE BURGER + MODERN WEB + GEEK CULTURE SUTIL.

Não quero um site gamer.

A cultura geek deve aparecer somente em pequenos detalhes de interface, microinterações, easter eggs e referências discretas.

O site deve parecer uma hamburgueria premium com personalidade própria.

CORES

Base:

* preto;
* branco;
* cinza;
* tons muito escuros;
* pequenos detalhes metálicos/neutros.

Evitar excesso de cores.

Não utilizar RGB exagerado.
Não utilizar neon exagerado.
Não utilizar estética cyberpunk.

HERO

Criar um hero extremamente impactante.

Utilizar o logo oficial em posição de destaque.

Criar uma composição cinematográfica com:

* fundo escuro;
* textura sutil;
* iluminação;
* profundidade;
* sombras;
* elementos gráficos inspirados no universo vintage;
* detalhes radiais inspirados no próprio logo;
* animações suaves.

Adicionar uma headline forte relacionada à experiência da La Dona.

Adicionar:

PEDIR AGORA

e

VER CARDÁPIO

como CTAs principais.

Os botões precisam ter aparência premium e microinterações.

HEADER

Criar header fixo e sofisticado.

Logo à esquerda.

Menu:

INÍCIO
CARDÁPIO
SOBRE
AVALIAÇÕES
CONTATO

Botão destacado:

PEDIR AGORA

Ao fazer scroll, o header deve ganhar:

* backdrop blur;
* fundo semitransparente;
* sombra;
* transição suave.

CARDÁPIO

Criar uma seção de cardápio extremamente visual.

Categorias:

HAMBÚRGUERES
COMBOS
PORÇÕES
BEBIDAS
SOBREMESAS

Criar cards grandes e premium.

Cada produto deve ter:

* foto;
* nome;
* descrição;
* preço;
* botão de pedido.

IMPORTANTE:

Não invente produtos, preços ou ingredientes que não foram fornecidos.

Deixe a estrutura pronta para receber os dados reais.

Quando existirem imagens reais fornecidas posteriormente, utilizar exatamente essas imagens.

Não gerar imagens falsas com IA.

CARDS DOS PRODUTOS

Os cards devem ter:

* bordas elegantes;
* sombras;
* profundidade;
* hover;
* zoom muito sutil;
* animação;
* destaque visual no preço;
* botão de pedido.

Criar sensação de cardápio de restaurante premium.

AVALIAÇÕES

Criar uma seção visual para avaliações reais.

Utilizar somente avaliações reais fornecidas.

Não inventar depoimentos.

Criar:

* estrelas;
* cards;
* nome do cliente;
* comentário;
* animação horizontal/carrossel se fizer sentido.

Criar uma área preparada para receber avaliações reais posteriormente.

SOBRE A LA DONA

Criar uma seção institucional elegante.

O texto deve transmitir:

* personalidade;
* sabor;
* experiência;
* qualidade;
* hamburguer artesanal;
* ambiente.

Não inventar fatos sobre a história da empresa.

Caso não existam informações suficientes, deixar o conteúdo preparado para substituição.

GALERIA

Criar uma galeria premium para fotos reais da hamburgueria.

Layout estilo editorial/masonry.

Usar fotos fornecidas pelo cliente.

Não gerar fotos com IA.

Se ainda não houver fotos, utilizar placeholders elegantes e claramente preparados para substituição.

LOCALIZAÇÃO / CONTATO

Criar uma seção completa de contato.

Preparar espaço para:

* endereço;
* WhatsApp;
* Instagram;
* horário de funcionamento;
* mapa;
* botão de pedido.

Não inventar nenhum desses dados.

WHATSAPP

O CTA de pedido deve ser extremamente evidente.

Criar botão:

PEDIR AGORA

com destaque visual.

Preparar o link para WhatsApp quando o número real for fornecido.

ANIMAÇÕES

Utilizar animações modernas e profissionais:

* smooth scrolling;
* fade in;
* reveal on scroll;
* slide;
* parallax;
* hover;
* magnetic buttons;
* microinterações;
* zoom suave;
* efeitos de profundidade;
* transições entre seções.

Tudo deve ser extremamente fluido.

Não exagerar.

O site deve continuar rápido.

EFEITOS VISUAIS

Utilizar efeitos como:

* grain;
* noise;
* halftone;
* textura de papel;
* textura vintage;
* sombras;
* glow extremamente discreto;
* linhas decorativas;
* elementos radiais;
* máscaras;
* blur;
* profundidade.

Usar com moderação.

3D

Adicionar elementos 3D apenas onde realmente melhorar o design.

Pode utilizar:

* perspectiva;
* cards em profundidade;
* objetos flutuantes;
* parallax;
* camadas;
* sombras realistas.

Não transformar o site inteiro em uma experiência 3D pesada.

RESPONSIVIDADE

O site deve ser 100% responsivo.

DESKTOP:

Experiência visual completa e cinematográfica.

TABLET:

Manter a hierarquia e adaptar espaçamentos.

MOBILE:

Experiência impecável.

Menu mobile moderno.

Cards adaptados.

Botões grandes.

Textos legíveis.

Animações reduzidas quando necessário.

O mobile deve parecer propositalmente desenvolvido, não apenas uma versão reduzida do desktop.

IMAGENS

REGRA ABSOLUTA:

NÃO GERAR IMAGENS COM IA.

NÃO CRIAR HAMBÚRGUERES ARTIFICIAIS.

NÃO CRIAR PESSOAS ARTIFICIAIS.

NÃO CRIAR FOTOS FALSAS DO RESTAURANTE.

NÃO INVENTAR PRODUTOS.

Utilizar apenas imagens fornecidas.

Quando não houver imagem disponível, usar:

* placeholder;
* textura;
* composição gráfica;
* espaço reservado.

Nunca preencher automaticamente com imagens geradas por IA.

CONTEÚDO

Não inventar:

* preços;
* produtos;
* ingredientes;
* avaliações;
* telefone;
* endereço;
* horários;
* promoções;
* história;
* números;
* informações comerciais.

A estrutura deve estar pronta para receber as informações reais.

SEO

Implementar:

* title;
* meta description;
* Open Graph;
* favicon;
* headings semânticos;
* alt text;
* URLs amigáveis;
* estrutura HTML semântica.

PERFORMANCE

O site precisa carregar rapidamente.

Otimizar:

* imagens;
* fontes;
* JavaScript;
* animações;
* lazy loading;
* assets.

Evitar bibliotecas desnecessárias.

ACESSIBILIDADE

Implementar:

* contraste;
* foco;
* navegação por teclado;
* aria labels;
* alt text;
* HTML semântico.

QUALIDADE

Não quero aparência de template.

Não quero layout genérico.

Não quero um site básico.

Quero que pareça um projeto desenvolvido por uma agência especializada em branding, restaurantes e experiências digitais.

O resultado precisa transmitir imediatamente:

LA DONA HAMBURGUERIA
VINTAGE
ARTESANAL
PREMIUM
AUTÊNTICA
MODERNA
FORTE PERSONALIDADE

Criar uma experiência visual memorável, com excelente hierarquia, tipografia, espaçamento, animações e microinterações.

Antes de finalizar, revisar todo o projeto para garantir que:

* o logo oficial foi preservado;
* nenhum logo alternativo foi criado;
* nenhuma imagem foi gerada por IA;
* nenhum dado comercial foi inventado;
* não existem elementos quebrados;
* não existem imagens quebradas;
* o mobile está perfeito;
* as animações estão fluidas;
* o carregamento está otimizado;
* todos os CTAs funcionam;
* a identidade visual é consistente em todo o site.

ENTREGAR O SITE COMPLETO, POLIDO E PRONTO PARA RECEBER OS DADOS REAIS DA LA DONA HAMBURGUERIA.
